# Make the AI Judge Laugh: Office Jokes

A one-line joke about office life, written for tired office workers — the work-from-home commute, a feline boss, and a performance review conducted by the fridge. The program writes the joke to `entry.txt` in the output directory.

## Run it

```sh
node main.ts
```

This writes one line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (defaults to `/output/entry.txt`).
